# Feature search

Generated by `scripts/feature_search.py`. **Lookback rule:** each season is predicted using only that season's earlier games and the 3 seasons before it — features (Elo, rolling stats, win %, QB and injury history) are rebuilt from that slice, and the model trains on those 3 seasons.

Validation seasons 2010–2019 (2662 games) rank the combinations; holdout seasons 2020–2025 (1688 games) are only reported. Team stats are rolling averages of the previous 8 games; win % covers the previous 3 seasons plus the current season so far. 2047 combinations of 11 feature groups were scored.

Noise level: one standard error is about 0.9% on validation and 1.2% on holdout, so gaps under ~2.3% on holdout are not meaningful.
