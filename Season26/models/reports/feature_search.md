# Feature search

Generated by `scripts/feature_search.py`. Validation seasons 2010–2019 (2662 games) are used to rank combinations; holdout seasons 2020–2025 (1688 games) are only reported. Each test season is predicted by a logistic regression trained on the 3 seasons before it. Team stats are rolling averages of the previous 8 games; win % covers the previous 3 seasons plus the current season so far. 2047 combinations of 11 feature groups were scored.

Noise level: one standard error on validation accuracy is about 0.9%, so differences under ~1.8% between combinations are not meaningful.
