# Feature search — with QB & injury features

Generated by `scripts/feature_search.py --extras`. **Lookback rule:** each season is predicted using only that season's earlier games and the 3 seasons before it — features (Elo, rolling stats, win %, QB and injury history) are rebuilt from that slice, and the model trains on those 3 seasons.

Validation seasons 2016–2019 (1063 games) rank the combinations; holdout seasons 2020–2025 (1688 games) are only reported. Team stats are rolling averages of the previous 8 games; win % covers the previous 3 seasons plus the current season so far. 3213 combinations of 17 feature groups were scored (up to 4 groups each).

Noise level: one standard error is about 1.5% on validation and 1.2% on holdout, so gaps under ~2.3% on holdout are not meaningful.

## Baselines (holdout)

- Always pick the home team: 53.9%
- Always pick the betting favorite: 66.6%
